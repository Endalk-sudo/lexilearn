## 1. Product Overview

LexiLearn is a **local-first, offline-capable English vocabulary learning web application** designed for individual users. It uses the **SM-2 spaced repetition algorithm** to optimize long-term word retention, with browser-based text-to-speech for pronunciation practice. All data is stored locally in SQLite — no cloud sync, no telemetry, no accounts.

### Target Users

- Self-directed English learners (TOEFL, IELTS, GRE, or general vocabulary improvement)
- Ethiopian users who want Amharic (አማርኛ) translations alongside English definitions
- Privacy-conscious learners who want full data ownership

### Key Differentiators

- **100% local** — SQLite database, no server-side user data, no third-party API calls
- **Browser TTS** — pronunciation generated by the OS, not external services
- **SM-2 spaced repetition** — scientifically-backed review scheduling
- **Amharic support** — built-in Amharic translations for vocabulary cards
- **No account required** — single-user app, zero friction to start

## 5. Technical Architecture

### 5.1 Stack

```
Frontend:  Next.js 16 (App Router, Turbopack, standalone output)
           React 19, TypeScript 5, Tailwind CSS v4
           Zustand (client state), Framer Motion (animations)
           Radix UI + shadcn/ui (component library)
           Recharts (charts)

Backend:   Next.js API Routes (single catch-all at /api/lexilearn)
           Prisma ORM 6.11, SQLite

DevOps:    pnpm, ESLint 9 (core-web-vitals + typescript)
```

### 5.2 Database Schema

```
Deck ──1:N── Word ──1:1── SrsCard
                          │
ReviewLog (per-review audit trail)
QuizSession (quiz completion records)
AppStat (key-value store: streak, XP, settings)
```

### 5.3 API Design

All API calls go through a single endpoint with action-based routing:

```
GET  /api/lexilearn?action=due|new|reviewable|decks|deck|dashboard|analytics|settings|quiz|search
POST /api/lexilearn?action=review|createDeck|addWords|addWord|updateWord|deleteWord|deleteDeck|quizSession|updateSettings|reset
```

### 5.4 SM-2 Algorithm

| Parameter | Description |
|-----------|-------------|
| Ease Factor | Starts at 2.5, min 1.3, adjusted per review quality |
| Intervals | 1d → 6d → EF×interval (capped at integer days) |
| Grades | 0 (Again), 3 (Hard), 4 (Good), 5 (Easy) |
| Mastery | ≥ 5 repetitions AND interval ≥ 21 days |

## 7. UI/UX Specifications

### 7.1 Navigation

- **Desktop:** Left sidebar with 7 navigation items (Dashboard, Learn, Review, Quiz, Decks, Stats, Settings) + search bar
- **Mobile:** Fixed bottom navigation bar with same items
- **Views:** Client-side routing via Zustand store (no page reloads)

### 7.2 Key Screens

1. **Dashboard** — Hero stats (due, new, daily goal, streak), XP/level progress, contribution calendar, card status overview, 7-day forecast
2. **Learn** — Card-by-card flow: Recall → Reveal → Spell → Grade → Next
3. **Review** — Flashcard with reveal, 4-grade buttons, keyboard shortcuts
4. **Quiz** — Mode selection → Quiz runner → Results summary
5. **Decks** — Grid of deck cards → Deck detail with word list, bulk add, CRUD
6. **Stats** — KPIs, weekly chart, pie chart, grade distribution, heatmap, per-deck table
7. **Settings** — TTS config, daily goal, theme, danger zone (reset)
8. **Search** — Search input → results list → word detail card

### 7.3 Design Tokens

- Font: Geist Sans + Geist Mono
- Theme: Light / Dark / System (via next-themes)
- Colors: Tailwind CSS v4 with OKLCH color space
- Animations: Framer Motion (view transitions, card reveals)

## 8. Known Limitations

| Limitation | Impact | Mitigation |
|------------|--------|------------|
| Single-user only | No multi-user or family sharing | By design — local-first privacy |
| No cloud sync | Data stays on one device | Export/import via CSV |
| Browser TTS quality varies | Linux may have no English voices | TTS diagnostics panel, Firefox recommendation |
| No mobile app | Web only | Responsive PWA-ready design |
| No API rate limiting | Not applicable (local-only) | N/A |
